# Security Research Portfolio

**Estado: repositorio reservado; sin laboratorios publicados.** Este espacio está destinado a estudios reproducibles de seguridad, correcciones y pruebas de regresión. Todavía no contiene hallazgos, código, demos ni resultados verificados.

## Criterios para publicar

- Usar sistemas propios o entornos con autorización explícita.
- Emplear datos sintéticos y eliminar credenciales, identificadores y rutas privadas.
- Documentar alcance, pasos de reproducción, impacto, corrección y prueba de regresión.
- Coordinar la divulgación responsable antes de publicar detalles de vulnerabilidades de terceros.
- Revisar derechos y licencia de cada material antes de añadirlo.

La ausencia de contenido técnico es intencional. No se atribuyen investigaciones o certificaciones que aún no estén documentadas.
